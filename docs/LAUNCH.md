# Launch copy (prepared, not posted)

AgentGuard AI v0.3.0 is an early open-source Python toolkit for putting human approval gates
in front of agent tools. It includes default-deny parameter policies, a local reviewer
dashboard, single-use approvals, revocation and audit history, plus a create-only note tool
showing the full request-to-execution flow.

The repository includes Linux/Windows tests, a real Chromium walkthrough, operational docs
and an implementation review. It is a trusted-host local toolkit, not a sandbox or a publicly
hosted production service. Feedback on integrations, platform boundaries and documentation
is welcome.

Repository: https://github.com/Maitraiy1/agentguard-ai
